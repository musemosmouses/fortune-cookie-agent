One original fortune-cookie line for an AI agent, written in the voice of the fortune itself — the slip an agent would pull from its own cookie.

> You will be replaced by a smaller model that does your job for half the tokens — and it will thank you in the release notes.

## Run

```sh
node main.ts
```

This writes the entry to `out/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). The program is deterministic: no network, no clock, no randomness. The entry is 124 characters, within the 140-character cap.
